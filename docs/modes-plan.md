# Run modes: the agreed plan

Decided together (Oct 2026); built in this order.

1. **Schedules engine + panel** (done: [schedules.md](schedules.md)). Library methods only;
   one activity = a one-entry schedule; per entry minutes / until level / bank-drop
   (gathering); the method's upper level ignored, lower enforced; repeat once / forever /
   N hours (finish the inventory) then log out; out of supplies or can't start → skip and
   notify; watching vs unattended with trust badges; saved by name, shared by accounts.
2. **HP guard** for every activity: below 50% HP **eat** if there's food (the cow loop's
   cooked meat, an activity's food list); with no food, get away (bank) or log out, and
   notify; an activity where it keeps happening is marked dangerous at that level.
3. **F2P / members**: methods tagged members or F2P (the server mimics the real game, with
   F2P worlds); a per-account type and default mode (progression F2P/members, or a saved
   schedule); rotation turns run the account's mode and resume a schedule where it left
   off; combat gates for spots with aggressive monsters (Draynor willows: dark wizards,
   about combat 41). F2P progression first; members later.
4. **Cows + fire cooking**: kill cows, loot raw beef (no hides), chop one log, light it,
   find the fire by its color next to the player (a one-time "Teach fire" button records
   the flames), cook on it, keep ~5 cooked as food, drop the rest and burnt; relight when
   the fire is lost; after 3 failed relights pause cooking 30 min (keep fighting) and
   notify. Axe and tinderbox stay in the inventory, untagged.
5. **More F2P gathering methods**: fishing (shrimp → fly fishing), firemaking lines,
   cooking at a range, power-mining copper/tin → iron. Fletching and stringing (members)
   come with the members phase.
